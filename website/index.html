Perguntas frequentes

O Overyn funciona no Windows?

Sim. A distribuição planejada é para Windows 10 e 11 em 64 bits.

O objetivo do aplicativo é manter dados de sessão e configurações organizados por perfil.

Posso configurar uma conexão diferente por perfil?

Sim. A interface foi preparada para configurações individuais por perfil.
