# Site Overyn

Landing page estática pronta para Vercel.

## Publicar
1. Na Vercel, importe este repositório.
2. Defina **Root Directory** como `website`.
3. Framework preset: **Other**.
4. Build command: deixe vazio.
5. Output directory: `.`.

## Instalador
Os botões de download já são interativos, mas exibem um modal enquanto não existe um binário publicado. Quando o instalador Windows estiver pronto, altere o handler `.js-download` em `app.js` para apontar para a URL real do `.exe`/`.msi`.

## Preview do aplicativo
O preview da interface é HTML/CSS e foi construído a partir da estrutura visual do próprio frontend do aplicativo (sidebar, visão geral, perfis, proxies e cards), para não depender de uma imagem genérica de outro produto.
